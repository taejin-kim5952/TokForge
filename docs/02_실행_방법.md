# 2. 실행 방법

> 설치 → 실행 → 진단 → 종료. Windows 11 기준.

## 사전 요구사항

| 항목 | 버전 | 확인 명령 |
|---|---|---|
| Python | 3.10 이상 | `python --version` |
| Ollama | 설치됨 + 실행 중 | `curl http://localhost:11434/api/tags` |
| Ollama 모델 | `gemma4:e2b` (또는 [config.py](../app/config.py) 의 `DEFAULT_MODEL`) | `ollama list` |

### Ollama 모델 받기

```powershell
ollama pull gemma4:e2b
```

→ 첫 실행 시 약 1.5GB 다운로드. 한 번 받으면 로컬에 캐시.

## 1. 설치

### 1-1. 저장소 받기

```powershell
git clone https://github.com/taejin-kim5952/TokForge.git
cd TokForge
```

이미 작업 중이라면 건너뛰기.

### 1-2. 가상환경 생성

```powershell
python -m venv .venv
```

→ 프로젝트 폴더에 `.venv\` 디렉터리 생성. 파이썬 인터프리터·패키지가 격리되어 다른 프로젝트와 충돌 안 함.

### 1-3. 가상환경 활성화

**PowerShell**:
```powershell
.\.venv\Scripts\Activate.ps1
```

**cmd**:
```cmd
.venv\Scripts\activate.bat
```

→ 프롬프트 앞에 `(.venv)` 표시되면 성공.

⚠️ PowerShell 에서 실행 정책 오류가 뜨면:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 1-4. 패키지 설치

```powershell
pip install -r requirements.txt
```

→ `sentence-transformers` 가 PyTorch 를 포함해 약 2GB 다운로드. 첫 설치 시 5~10분 소요 가능.

설치 검증:
```powershell
pip list
```
→ `fastapi`, `uvicorn`, `httpx`, `sentence-transformers`, `faiss-cpu` 가 보이면 OK.

## 2. 실행

### 2-1. 서버 기동

```powershell
python -m uvicorn main:app --reload
```

| 인자 | 의미 |
|---|---|
| `main:app` | `main.py` 파일의 `app` 객체 |
| `--reload` | 코드 수정 시 자동 재기동 (개발용) |

⚠️ `uvicorn main:app --reload` (앞에 `python -m` 없이) 실행해도 되지만, 가상환경 PATH 인식 이슈가 있는 경우 `python -m` 방식이 안전.

기대 로그:
```
INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     Started reloader process
INFO:     Application startup complete.
```

### 2-2. (첫 실행 1회만) 임베딩 모델 다운로드

Step 2 의 의미 캐시가 사용하는 임베딩 모델이 첫 사용 시 자동 다운로드:

```
Downloading sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 (~120MB)
```

→ `~/.cache/huggingface/` 에 캐시. 이후 실행은 즉시.

## 3. 진단

### 3-1. 헬스체크

브라우저 또는:

```powershell
curl http://localhost:8000/health
```

기대 응답:
```json
{
  "status": "ok",
  "ollama": "connected"
}
```

| 응답 | 의미 |
|---|---|
| `ollama: "connected"` | Ollama 정상 ✅ |
| `ollama: "disconnected"` | Ollama 미실행 — 윈도우 트레이에서 실행 확인 |

### 3-2. Swagger UI

```
http://localhost:8000/docs
```

→ 모든 엔드포인트 확인 가능. 그룹:

```
default          /, /health, /v1/chat/completions, /v1/models, /v1/models/current
cache            /v1/cache/stats
rag              /v1/rag/upload, /v1/rag/search, /v1/rag/stats
```

### 3-3. 채팅 테스트 (Ollama 까지 한 번에 검증)

Swagger UI 의 `POST /v1/chat/completions` → "Try it out" → 다음 JSON 입력:

```json
{
  "messages": [
    {"role": "user", "content": "안녕"}
  ]
}
```

→ Execute → OpenAI 형식의 응답 JSON 반환되면 **TokForge → Ollama 통합 정상**.

### 3-4. 캐시 동작 확인

같은 질문을 두 번 보내고:

```powershell
curl http://localhost:8000/v1/cache/stats
```

→ `total_cached: 1` 이면 캐시 저장 성공.

## 4. Continue.dev 연결

상세는 [3. Continue.dev 연결 설정](03_Continue_연동.md) 참고. 핵심만:

`%USERPROFILE%\.continue\config.yaml`:

```yaml
- name: TokForge
  provider: openai
  model: gemma4:e2b
  apiBase: http://127.0.0.1:8000/v1
  apiKey: local
  roles:
    - chat
```

VSCode 재시작 → Continue 패널에서 `TokForge` 선택 → 채팅.

## 5. 종료

### 서버 정지

uvicorn 터미널에서 `Ctrl + C`.

### 가상환경 비활성화

```powershell
deactivate
```

→ 프롬프트의 `(.venv)` 사라짐.

---

## 자주 만나는 오류

### `uvicorn: command not found`

→ 가상환경 활성화 안 됨. `.\.venv\Scripts\Activate.ps1` 다시.
→ 또는 `python -m uvicorn ...` 형태로 실행.

### `Error loading ASGI app. Attribute "app" not found`

→ 작업 디렉터리가 `TokForge/` 가 아님. `cd TokForge` 후 재실행.

### `RuntimeError: ... could not open ... .faiss for writing: Illegal byte sequence`

→ Windows 한글 경로 + FAISS 버그. **이미 우회 처리됨** — 발생하면 [step02 트러블슈팅](step02_의미캐시.md#트러블슈팅) 참고.

### `ollama: "disconnected"` 가 계속 표시

→ Ollama 데몬 미실행. 작업 표시줄 트레이에서 Ollama 아이콘 확인 / 재시작.
→ 또는 `ollama serve` 수동 실행.

### 채팅 응답이 매우 느림

→ 첫 호출은 모델 로딩으로 5~30초 소요 가능 (이후엔 빠름).
→ 영구히 느리면 Ollama 가 GPU 가속 못 쓰는 상태일 수 있음 → `ollama ps` 로 확인.

## 빠른 재실행 (이미 설치된 환경)

매번 처음부터 안 해도 됨. 이미 한 번 설치한 후:

```powershell
.\.venv\Scripts\Activate.ps1
python -m uvicorn main:app --reload
```

→ 두 줄이면 끝.
