# 2. 실행 방법

> 설치 → 실행 → 진단 → 종료. Windows 11 기준.

## 사전 요구사항

| 항목 | 버전 | 확인 명령 |
|---|---|---|
| Python | 3.10 이상 (3.11 권장) | `python --version` |
| Node.js (프론트용) | 18 이상 | `node --version` |
| Ollama | 설치됨 + 실행 중 | `curl http://localhost:11434/api/tags` |
| Ollama 모델 | `gemma3:1b`, `gemma4:e2b`, `gemma4:latest` | `ollama list` |
| Google Cloud Console 계정 | OAuth credentials 발급용 | https://console.cloud.google.com |

### Ollama 모델 받기

```powershell
ollama pull gemma3:1b
ollama pull gemma4:e2b
ollama pull gemma4:latest
```

→ 첫 실행 시 1.5-3GB 씩 다운로드.

## 1. 설치

### 1-1. 저장소 받기

```powershell
git clone https://github.com/taejin-kim5952/TokForge.git
cd TokForge
```

### 1-2. 가상환경 생성

```powershell
python -m venv .venv
```

### 1-3. 가상환경 활성화

**PowerShell**:
```powershell
.\.venv\Scripts\Activate.ps1
```

**cmd**:
```cmd
.venv\Scripts\activate.bat
```

→ 프롬프트 앞에 `(.venv)` 표시되면 성공.

⚠️ PowerShell 실행 정책 오류 시:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 1-4. 패키지 설치 ⚠️ Microsoft Store Python 주의

```powershell
$env:PYTHONNOUSERSITE = "1"
python -m pip install --no-cache-dir -r requirements.txt
```

> **`PYTHONNOUSERSITE = "1"`이 핵심**입니다. Microsoft Store 버전 Python은 user-site가 venv를 오염시켜 `ImportError`가 발생합니다. **모든 python/pip 명령 전에 이 환경변수 설정**.
>
> 자세한 내용: [개발내용/11-troubleshooting.md](../../개발내용/11-troubleshooting.md#venv)

설치 시간: 3-10분 (~1GB).

### 1-5. (옵션) PyTorch CUDA 빌드 (NVIDIA GPU 있을 때)

GPU 가속으로 임베딩 5-20배 빠름:

```powershell
python -m pip install --force-reinstall torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
```

검증:
```powershell
python -c "import torch; print('CUDA:', torch.cuda.is_available())"
```
→ `CUDA: True` 면 GPU 가속. False여도 동작은 함 (CPU fallback).

## 2. Google OAuth 셋업 (로그인 기능 사용 시)

로그인/프로젝트 기능 없이 채팅만 쓸 거면 건너뛰어도 됨.

### 2-1. Google Cloud Console에서 OAuth 발급

상세 절차: [개발내용/06-authentication.md](../../개발내용/06-authentication.md#3-google-cloud-console-설정)

요약:
1. Google Cloud Console → APIs & Services → Credentials
2. **OAuth 2.0 Client ID** 생성 (Web application)
3. Authorized redirect URIs 등록:
   - `http://localhost:8000/auth/google/callback` (로컬)
   - `https://api.tokforge.ai.kr/auth/google/callback` (운영)
4. Consent Screen → Test users에 본인 Gmail 추가

발급된 `client_id` + `client_secret` 복사.

### 2-2. `.env` 생성

```powershell
Copy-Item .env.example .env
```

`.env` 편집:
```
# Google OAuth
GOOGLE_CLIENT_ID=xxxxx-xxxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxx
GOOGLE_REDIRECT_URI=http://localhost:8000/auth/google/callback

# 환경
ENV=dev
LOG_LEVEL=INFO

# Langfuse (사용 안 하면 false)
LANGFUSE_ENABLED=false
```

전체 환경변수 목록: [개발내용/09-environment.md](../../개발내용/09-environment.md)

## 3. 실행

### 3-1. 서버 기동

```powershell
$env:PYTHONNOUSERSITE = "1"
python -m uvicorn main:app --reload --port 8000
```

기대 로그:
```
INFO    app.services.prompt_repo | prompts seeded: ['refiner', 'classifier', 'compressor', 'system']
INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     Application startup complete.
```

→ 첫 기동 시 4종 프롬프트가 DB(`storage/monitor.db`)에 자동 seed됨.

### 3-2. (첫 실행 1회만) 임베딩 모델 다운로드

Step 2의 의미 캐시가 사용하는 임베딩 모델이 첫 사용 시 자동 다운로드:

```
Downloading sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 (~120MB)
```

→ `~/.cache/huggingface/` 에 캐시. 이후 즉시.

## 4. 진단

### 4-1. 헬스체크

```powershell
curl http://localhost:8000/healthz
```

### 4-2. Swagger UI

```
http://localhost:8000/docs
```

→ 모든 엔드포인트 (chat / cache / rag / admin / auth / projects / me 등) 표시.

### 4-3. Admin 상태 확인

```powershell
curl http://localhost:8000/admin/status
```

기대: Ollama 연결 상태, 사용 모델, 단계 활성화, 통계 한 번에.

### 4-4. 채팅 테스트

```powershell
curl -X POST http://localhost:8000/v1/chat/completions `
  -H "Content-Type: application/json" `
  -d '{\"messages\":[{\"role\":\"user\",\"content\":\"안녕\"}]}'
```

→ OpenAI 형식 응답 JSON. 8단계 파이프라인이 자동 수행.

### 4-5. OAuth 로그인 테스트 (브라우저로)

```
http://localhost:8000/auth/google/login?return_to=/projects
```

→ Google 로그인 → callback → 쿠키 발급 → 프론트로 redirect.

이어서 `/me` 호출:
```powershell
curl --cookie "tf_session=<쿠키값>" http://localhost:8000/me
```

→ 본인 정보 JSON 반환.

## 자주 만나는 오류

전체 트러블슈팅: [개발내용/11-troubleshooting.md](../../개발내용/11-troubleshooting.md)

### `ImportError: cannot import name 'PreTrainedModel' from 'transformers'`

→ Microsoft Store Python의 user-site 침투. `$env:PYTHONNOUSERSITE = "1"` 후 재설치.

### `uvicorn: command not found`

→ 가상환경 활성화 안 됨, 또는 `python -m uvicorn ...` 형태로 실행.

### `Error loading ASGI app. Attribute "app" not found`

→ 작업 디렉터리가 `TokForge/` 가 아님. `cd TokForge` 후 재실행.

### `RuntimeError: ... could not open ... .faiss for writing: Illegal byte sequence`

→ Windows 한글 경로 + FAISS 버그. **이미 우회 처리됨** — 발생하면 [step02 트러블슈팅](step02_의미캐시.md#트러블슈팅) 참고.

### `ollama: "disconnected"`

→ Ollama 데몬 미실행. 작업 표시줄 트레이에서 Ollama 아이콘 확인 / 재시작.

### OAuth `redirect_uri_mismatch`

→ Google Cloud에 등록된 URI와 `.env`의 `GOOGLE_REDIRECT_URI`가 한 글자라도 다름. http vs https, 끝 슬래시, 포트 확인.

### `sqlite3.OperationalError: no such table`

→ `init_schema()` 호출 누락. `main.py`의 라우터 등록 위에 `xxx_repo.init_schema()`가 있어야 함.

### 채팅 응답이 매우 느림

→ 첫 호출은 모델 로딩으로 5-30초. 이후 정상.
→ 영구히 느리면 GPU 가속 미작동 → `ollama ps` 의 `PROCESSOR` 컬럼 확인 (100% GPU 이상적, 100% CPU 의심).
